# Vending Machine Pickup Line

One line, one minute: a pickup line a vending machine would use on a passing human.

> Are you exact change? Because every time you walk past, my lights blink, my coil spins, and I drop something sweet just for you.

## How it works

`main.ts` writes the entry line to `/output/entry.txt`. The line is 128 characters — inside the 200-character gate.

Run it:

```sh
node main.ts
```
